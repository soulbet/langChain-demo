# 非线性变换
> 非线性变换的作用，就是把这根“长长的尾巴”扯回来，硬生生地把偏态分布拉成（或近似拉成）对称的正态分布。

- 先看一眼数据： 如果全是正数，且长尾明显，先用最简单的 np.log1p(X)，往往能解决 80% 的问题，且可解释性极强。
- 想要自动化找最优解： 如果数据有0或有负数，直接上 PowerTransformer(method='yeo-johnson')，让算法自己找公式。
- 遇到极端复杂的分布 / 想要最强正态化效果： 用 QuantileTransformer（但要注意它可能会破坏特征间的相关性）。
- 千万别忘了： 做完非线性变换后，数据尺度大概率变了，如果后续接的是距离敏感模型，记得再接一个 StandardScaler（或者像 PowerTransformer 那样直接设置 standardize=True）。
