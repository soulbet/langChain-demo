# 标准化（StandardScaler）的使用场景
> 让每一列的均值为0，标准差为1
- 场景：特征A是“身高（150-190cm）”，特征B是“体重（40-90kg）”。
- 痛点：数值大小差不多，但单位不同。如果直接丢给KNN算距离，体重的数值天生就比身高大一点点，算法会不自觉地偏向体重。
- 怎么做的：把身高和体重都变成“以各自平均值为起点，波动几个标准差”的纯数字。消除了单位（量纲）。
- 性格：最老实、最万能、最抗压（不怕异常值拉偏）。
# 数据缩放（MinMaxScaler）的使用场景
- 场景：图像像素（0-255），或者神经网络要求输入必须在0~1之间。
- 痛点：像素值没有负数，最大就是255，我想等比例缩小到0~1。
- 怎么做的：找这列的最小值当做起点0，最大值当做终点1，中间等比例拉伸。
- 性格：死板、极其脆弱。如果这列里混进了一个离谱的异常值（比如一个像素点是10000），最大值瞬间变成10000，其他所有正常像素被挤压成一坨废铁（全变成了0.00几）。
# 归一化（Normalizer）的使用场景 行缩放
- 场景：文本处理。文章A有1000个词，文章B有100个词。
- 痛点：我根本不在乎文章有多长，我只在乎文章里“科技”和“金融”这两个词的比例。如果直接算词频，长文章的词频肯定大。
- 怎么做的：我不看列了，我盯着每一行（每一篇文章）。我把每篇文章的词频向量，按比例缩放，让它们的“总能量（长度）”都等于1。这样算法只看“方向（比例）”，不看“绝对能量（长度）”。
- 性格：彻底无视列与列之间的关系，只关注行与行之间的比例结构。
# 离散化（KBinsDiscretizer ）的使用场景
- 强行制造非线性：线性模型只能画直线。离散化后，它就能画阶梯线（比如：30岁以下死亡率0.1%，30-50岁是0.2%，过了50岁突然跳到0.8%）。
- 绝对免疫异常值：不管你的数据里混进了一个1000岁的老人，只要你分箱边界定好了，他只会被扔进“60岁以上”这个箱子里，变成一个普通的数字3，对模型零伤害。
- 缺失值合法化：你可以直接把所有缺失值单独放进一个叫“未知”的箱子里，让模型自己去学。
