# 归一化
> 归一化是对单个样本进行缩放以使得 单位规范  
> 注意：它是按行操作的！（前面讲的 StandardScaler 和 MinMaxScaler 都是按列操作的）。
- L2 基于欧几里得长度（勾股定理）。常用于文本处理、计算余弦相似度。
   - Xij = Xij / sqrt(sum(Xi^2))    
- L1 基于曼哈顿长度（绝对值之和）。缩放后，该行所有元素的绝对值之和等于 1。
   - Xij = Xij / sum(abs(Xi))
- Max归一化
   - Xij = Xij / max(abs(Xi))
- 列缩放（如 StandardScaler）：是为了解决“苹果和橘子不能直接相加”的问题（比如身高用厘米，体重用千克，量纲不同）。
- 行归一化（Normalizer）：是为了解决“大象和蚂蚁”的问题。哪怕大象的各项指标都比蚂蚁大 100 倍，只要它们身体各部分的比例（长宽高）是一样的，在 Normalizer 眼里，它们就被投射到了同一个方向上，变成了同一种形状。这在**文本处理（词频向量）**中极其有用，因为长文章和短文章的单词总数差别巨大，但我们只关心词语出现的“比例结构”。
