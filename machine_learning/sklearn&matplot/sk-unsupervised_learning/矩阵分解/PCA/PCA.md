
# PCA
> PCA 是一种线性降维技术，通过正交变换将原始特征转换为一批线性不相关的新特征（主成分），并按方差从大到小排列，使得我们能以最小的信息损失将高维数据压缩到低维。
## 核心思想
> PCA 的目标是：找到数据中方差最大的方向。
- 想象一组二维数据点（像一根压扁的香肠）：
  - 第一主成分（PC1）：数据方差最大的方向（香肠的长轴） 
  - 第二主成分（PC2）：与 PC1 正交且方差第二大的方向（香肠的短轴） 
  - 降维：丢掉短轴方向（信息损失最小），只保留长轴方向
## 数学原理
- 最大投影方差
- 最小重构误差
- 协方差矩阵特征分解

### 协方差矩阵特征分解
- 步骤：
  - 中心化：X_c=X-avg(X_c)
  - 计算协方差：Σ=1/(n-1) * X_c^T * X_c
  - 特征分解：Ax=λx
  - 排序：按特征值λ 从大到小排序
  - 选择前面K个特征向量作为主成分
- 输出：
  - 主成分（载荷）：特征向量v，表示新坐标轴的方向
  - 主成分得分：X_cv，表示数据点在新坐标轴上的坐标值
  - 解释方差： λ/Σλ，表示第i 个主成分保留的信息比例
## 应用场景：
降维可视化	将高维数据投影到 2D/3D 观察	n_components=2
加速模型训练	减少特征数，提升效率	保留 90%-99% 方差
去噪	丢掉小方差成分（可能是噪声）	保留 80%-95% 方差
特征提取	获得新的不相关特征	根据需求选择
预处理	为其他算法（如K-Means）降维	保留 95%-99% 方差
