# 层次聚类（Hierarchical Clustering）
> 层次聚类是一种通过构建树状结构来展示数据点之间嵌套关系的聚类方法，它不需要预先指定簇的数量，而是生成一个层次化的聚类树（树状图，Dendrogram），
  你可以根据需要的粒度来选择聚类结果。
- 核心思想：从"个体"到"整体"
  - 层次聚类有两种构建方向：
  1. 凝聚式（Agglomerative）	自底向上	每个点自成一簇，反复合并最相似的两簇	n 个簇	1 个簇
  2. 分裂式（Divisive）	自顶向下	所有点在一个簇，反复分裂最不相似的簇	1 个簇	n 个簇
- 最常用凝聚式：  
   `初始状态：每个数据点 = 一个簇  
      ●  ●  ●  ●  ●
      ↓ 计算所有簇间距离
      ↓ 找到最近的两个簇
      ↓ 合并它们
     重复以上过程，直到只剩一个簇`
   示例：  
     步骤0: [A] [B] [C] [D] [E]        ← 5 个簇
     步骤1: [A,B] [C] [D] [E]          ← 合并最相似的(A,B)
     步骤2: [A,B] [C,D] [E]            ← 合并(C,D)
     步骤3: [A,B] [C,D,E]              ← 合并(C,D) 与 E
     步骤4: [A,B,C,D,E]                ← 合并所有
- 簇间距离的度量方法：
  1. 单链接 (Single)min_(a∈A,b∈B) d(a,b)	最近距离，易产生链状簇	细长、不规则
  2. 全链接 (Complete)max_(a∈A,b∈B) d(a,b)	最远距离，倾向紧凑簇	球形、紧密 
  3. 平均链接 (Average)  两簇之间所有点对距离的平均值
  4. Ward 法  |C_i|*|C_j|/(|C_i|+|C_j|) * ||μ_i-μ_j||^2  选择合并后使整个聚类的总误差平方和（SSE）增加最小的那两个簇    均衡球形
     C_i,C_j 待合并的两个簇，|C_i|，|C_j|：簇的大小(样本数)，μ_i，μ_j：簇的均值向量
  5. 质心法   ||μ_i-μ_j||^2  直接用两簇质心的距离
  6. 中位数法  ||μ_i-μ_j||^2     |C_i|，|C_j|：是加权中位数（实际上是质心的递归平均）。
- 场景选择
通用场景	Ward	最稳定，产生均衡的球形簇
发现链状/不规则簇	Single	能发现细长结构，如"微笑曲线"
需要紧凑簇	Complete	倾向产生大小相似的球形簇
折中方案	Average	介于 Single 和 Complete 之间
有噪声数据	Ward 或 Complete	Single 容易被噪声点桥接
基因/文本分析	Average	经典选择，表现稳定
