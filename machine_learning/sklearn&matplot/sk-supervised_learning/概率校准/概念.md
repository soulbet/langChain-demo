# CalibratedClassifierCV
1. 补全概率输出SVM 等模型原本只输出决策分值，无 0~1 概率，套用 Sigmoid 后生成标准概率形式。
2. 修正概率偏差即便能输出概率的模型，原始置信度存在偏移，缩放后贴合真实事件发生概率。
## 校准方法
- Platt 缩放（Platt Scaling）
  - 用Sigmoid 函数把输出扭成标准概率
  - 适合线性模型、SVM
  - 简单、平滑
- 保序回归（Isotonic Regression）
  - 你刚学的！单调非线性拟合
  - 适合数据量大的情况
  - 比 Platt 更准，但容易过拟合
- 工作流程
  - 训练基础模型（SVM、随机森林、XGBoost）
  - 用交叉验证得到预测概率
  - 用 Platt / Isotonic 拟合修正概率
  - 最终输出校准后的真实置信度
- 场景
  - 需要真实可信的概率（风控、医疗、推荐、信用评估）
  - 模型输出概率不可靠（SVM、随机森林、XGBoost）
  - 多分类模型置信度要公平

## 1. 输出本质≠真实概率
1. 不少模型输出值只是置信打分，并非严格数学概率
- SVM：输出决策函数距离，仅代表样本离分类边界远近，不满足 0~1 真实概率分布
- 随机森林：类别投票占比，样本分布不均时，占比会偏离实际发生概率
- 树模型：节点统计频次，受分裂规则、样本划分影响，存在系统性偏移
2. 模型固有假设偏差
- 逻辑回归理论概率合规，但特征缩放、异常样本会破坏概率分布
- 模型拟合优先追求分类对错，不以概率精准度为优化目标，决策边界优先，置信度附带产出
3. 训练数据分布问题
- 类别不平衡：少数类预测概率普遍虚低，多数类虚高
- 样本噪声、离群点：干扰打分尺度，拉高 / 压低置信数值
- 训练集与测试集分布差异，训练拟合的概率规律泛化失效
4. 算法计算机制缺陷
- 集成模型投票均分，打分区间被压缩或拉伸，概率区间失真
- 非线性模型映射关系复杂，输出数值无法严格贴合事件真实发生概率
