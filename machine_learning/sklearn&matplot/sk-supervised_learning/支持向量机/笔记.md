# Svc、NUSvc、LinearSvc区别
1、公共基础
  - SVC、NuSVC 底层都是 libsvm
  - LinearSVC 底层是 liblinear，完全另一套实现  

2、SVC 特点
  - 超参数是 C 惩罚系数
  - 支持多种核函数：linear、poly、rbf、sigmoid
  - 可做线性、也可做非线性分类
  - 多分类默认 OVO 一对一
  - 适合中小样本，大样本训练慢
  - 靠调 C 控制过拟合与错分程度  


3、、NuSVC 特点
  - 是 SVC 的等价变体，只是换了参数形式
  - 超参数是 nu，范围 (0,1]
  - nu 可直观控制：支持向量比例、错误样本上限
  - 同样支持所有核函数，可线性可非线性
  - 底层同样 libsvm，多分类也是 OVO
  - 不用猜 C，用比例调参更直观
4、LinearSVC 特点
  - 只能线性，不支持任何核函数
  - 无 kernel 参数，专为线性场景优化
  - 大样本、高维稀疏数据训练速度远快于前两个
  - 多分类默认 OVR 一对多
  - 支持 L1、L2 正则，L1 可做特征筛选
  - 损失函数可选 hinge、squared_hinge
  - 适合文本分类、超大样本线性建模
5、核心差异总结列表
  - 参数不同：SVC 用 C，NuSVC 用 nu，LinearSVC 用 C 且无核
  - 核函数：SVC/NuSVC 支持核；LinearSVC 不支持
  - 底层库：SVC/NuSVC 是 libsvm；LinearSVC 是 liblinear
  - 多分类：SVC/NuSVC OVO；LinearSVC OVR
  - 适用规模：LinearSVC 适合大数据；另外两个适合中小数据
  - 非线性能力：SVC/NuSVC 有；LinearSVC 无

# 点到平面的计算公式
## 平面工程已知
平面：Ax + By + Cz + D = 0  
点：x0,y0,z0  
点到平面的距离：  
d = |Ax0 + By0 + Cz0 + D| / sqrt(A^2 + B^2 + C^2)
## 向量法（已知平面一点与法向量）
平面过点：Q(X1,Y1,Z1),平面法向量：N(A,B,C)  
点到平面的距离：   
d = QP * N / |N|  
QP = (X2 - X1, Y2 - Y1, Z2 - Z1)  
分子：投影的绝对值（点积的绝对值）  
分母：法向量的长度  

# 法向量
> 法向量是垂直于平面（或曲线、曲面）的向量。法向量是平面方程的“骨架”，有了法向量和一个点，平面唯一确定。

平面：Ax + By + Cz + D = 0  
法向量：(A,B,C)
