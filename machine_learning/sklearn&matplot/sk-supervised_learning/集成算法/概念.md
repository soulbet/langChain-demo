# 平均法
> 该方法的原理是构建多个独立的估计器，然后取它们的预测结果的平均，一般来说，组合之后的估计器是会比单个估计器要好的，因为它的方差减小了。  
> 代表算法：Bagging、Forests of randomized trees

## Bagging
> 在原始训练集的随机子集上建立多个基模型，再聚合预测结果，通过引入随机化降低单个模型的方差，减少过拟合。
- Bagging 是一种并行集成方法：
  - 采样：对训练数据做多次随机抽样，生成多个不同的训练子集
  - 训练：每个子集独立训练一个同类型的基模型（如决策树）
  - 聚合：所有模型的预测结果通过投票 / 取平均得到最终输出
- 关键优势
  - 对高方差、易过拟合的模型（如完全生长的决策树）效果最好
  - 不依赖基模型的底层细节，无需复杂调参就能提升性能
  - 核心目标是降低方差，提升模型稳定性与泛化能力
  - 与 Boosting 形成互补：Boosting 擅长提升弱模型、降低偏差；Bagging 擅长降低强模型的方差
### Bagging 四大核心变种
> 本质区别在于随机子集的抽取对象和方式
- Pasting（粘贴法）
  - 仅样本子集	
  - 无放回抽样	
  - 样本不重复，适合小数据集，计算开销小	
  - 小规模、低噪声数据
- Bagging（标准）	
  - 仅样本子集	
  - 有放回抽样（Bootstrap）	
  - 经典形式，样本可重复，天然自带袋外（OOB）数据	
  - 通用场景，如随机森林的基础
- Random Subspaces（随机子空间）	
  - 仅特征子集	
  - 无放回 / 有放回抽样	
  - 对特征随机采样，降低特征维度，减少特征间相关性	
  - 高维数据（如图像、文本）
- Random Patches（随机补丁）	
  - 样本 + 特征子集	
  - 同时抽样	
  - 既随机采样本，又随机采特征，双重随机化	
  - 超大规模高维数据
## 随机森林-Random Forest
> 随机森林本质是决策树 + Bagging + 特征随机化，通过两个核心随机化步骤降低单棵树的方差
1. 样本层面：Bootstrap 自助采样:
> 每棵树的训练集都是从原始数据中有放回随机抽取的（和标准 Bagging 一样）  
  - 特点：
  单棵树的训练集约包含 63.2% 的原始样本，剩余 36.8% 为袋外数据（OOB）
  OOB 可直接用来评估模型泛化误差，无需额外划分验证集
  - 作用：让每棵树的训练数据都有差异，避免树完全一样，降低整体方差
2. 特征层面：节点分裂时的随机特征选择
> 构建树的每个节点时，不使用全部特征，而是从 max_features 个随机特征中选最优分裂点
  - 文本公式（常用设置）：
    - 分类任务：max_features = sqrt(n_features)
    - 回归任务：max_features = n_features / 3
  - 作用：
    - 降低树之间的相关性（如果所有树都用同一个特征分裂，结果会高度相似）
      让模型更关注弱特征，避免少数强特征主导分裂，提升泛化能力
## 极端随机数-Extra Tree
> 不做数据采样（用全量数据） + 节点随机选特征 + 分裂点完全随机（不找最优）  
- 原理
  - ET：每棵树 用全部训练样本，不抽样
  - 每个节点分裂时，随机选一个特征子集（分类默认√p，回归默认 p/3）
  - 对选中特征，在特征取值范围内随机挑一个阈值，不计算最优；再从几个随机分裂里选相对好的
- 优点
  - 训练极快：不用遍历阈值找最优，大数据 / 高维场景优势明显
  - 方差更低、更稳：树之间差异更大，集成后抵消随机误差效果更好
  - 抗噪声强：随机分裂不刻意拟合噪声，对脏数据、异常点鲁棒
  - 高维友好：随机特征 + 随机分裂，天然适合特征很多、冗余强的数据
- 缺点
  - 单棵树精度略低：随机分裂不如最优分裂贴合数据
  - 小样本可能不如 RF：数据少时，全量训练 + 随机分裂易欠拟合

# 提升法
> 基估计器是按顺序建立的，并且试图减小组合估计器的偏差。其动机是将几个弱模型结合起来，形成一个强大的整体。
> 代表算法：AdaBoost、Grandient Tree Boosting
## AdaBoost
> 属于Boosting 串行集成，串行训练弱分类器，前序模型错分样本加重权重，后续模型重点纠正错误，整体降偏差，把弱模型拼成强模型。  
- 核心机制
  - 样本权重更新初始所有样本权重一致，每轮训练后：
    - 分类正确：降低样本权重
    - 分类错误：大幅提高样本权重
  - 下一轮弱学习器优先学习高权重难分样本
    - 通过权重控制训练参数更偏向权重大的样本进行调整 
    - 弱模型权重分配误差越小的弱分类器，最终投票话语权越大；误差大的模型权重压低。
- 训练流程
  - 初始化全局样本权重
  - 迭代训练若干个弱分类器（常用单层决策树 / 决策树桩）
  - 计算本轮模型误差，分配模型权重
  - 依据预测对错更新样本权重
  - 全部训练完成，加权组合所有弱模型输出结果
- 特点
  - 训练串行顺序执行，无法并行，速度慢于 Bagging
  - 聚焦拟合难分样本，擅长纠正偏差，不擅长降方差
  - 对异常值、噪声样本极度敏感，容易过度偏向错分样本
  - 弱基模型首选：决策树桩、单层决策树
  - 无需调参即可快速提升基线效果
- 优点
  - 逻辑简单，实现容易
  - 无需先验知识，自动聚焦困难样本
  - 小数据集上提升效果明显
- 缺点
  - 对噪声、离群点极其敏感
  - 串行训练耗时久
  - 多分类场景表现一般，更适配二分类

## GradientBoosting
> 通过拟合上一个模型的残差，
- 逻辑
  - 第一棵树：正常拟合数据
  - 计算预测误差（残差）
  - 第二棵树不去拟合原始数据，而是去拟合这个误差！
  - 第三棵树拟合前两棵的总误差
  - 最后把所有树的结果加起来 = 最终预测
- 与AdaBoost相比
  - 不依赖样本权重，不会死磕噪声
  - 用梯度（残差）指导训练，更稳定
  - 可用于分类 / 回归 / 排序，全能
  - 精度极高，是传统机器学习天花板之一
  - 可控性强（学习率、树深度、正则）
### HistGradientBoosting
> 把连续特征分成 256 个桶（直方图）, 分裂只在桶之间找，不再遍历所有值, 速度爆炸快，百万样本秒级训练  
- 速度极快（大数据首选）
- 内存极低
- 自带处理缺失值（不用 fillna！）
- 自带分桶归一化（不用标准化！）
- 比普通 GBDT 更不容易过拟合
- 支持类别特征（categorical_feature）
> 对于类别特征，不需要编码，直接类别处理
## Voting
> 就是把多个不同模型放一起，让它们投票决定最终结果，属于集成学习里最简单、最暴力、最稳定的一种。
- 核心逻辑（你秒懂）
  - 你现在有 3 个模型：
    - 逻辑回归（LR）
    - 决策树
    - SVM
    - KNN
  - 测试一个样本：
    - LR 说：类别 0
    - 决策树说：类别 1
    - SVM 说：类别 1
    - KNN 说：类别 0
>投票结果：类别 1 有 2 票 → 最终输出类别 1 这就是 VotingClassifier。

## Stacking
> 分层堆叠集成，模型分层接力预测，底层模型输出结果当作上层特征再训练，比单纯投票融合效果更强。
- 核心流程
  - 第一层（基模型层）
    - 训练多个异构模型，对训练集做交叉验证预测，输出预测结果 / 概率。
  - 特征重构
    - 把所有基模型的输出拼接，组成全新特征数据集。
  - 第二层（元模型层）
    - 用新特征训练一个简单模型（比如逻辑回归），通过调整新特征的权重，拟合真实标签
- 优缺点
  - 优点
    - 融合能力远超投票，精度上限更高
    - 充分利用不同模型学习偏好，适配复杂数据
  - 缺点
    - 训练耗时成倍增加
    - 层级越多越易过拟合
    - 可解释性弱，调参复杂度高
