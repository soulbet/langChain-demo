# 连接函数的作用
- 适应非正态分布：将响应变量（如计数、概率）转换为线性可建模的形式。
- 确保预测合理性：例如，对数连接确保预测值非负，Logit 连接确保预测值在 (0,1) 范围内。
- 统一框架：将线性回归、逻辑回归、泊松回归等统一为 GLM 的特例。


1. 恒等连接（Identity Link）
- 公式：g(μ)=μ
- 应用：普通线性回归（正态分布响应变量）。
- 特点：直接将线性预测器作为期望值，无需变换。
2. 对数连接（Log Link）
公式：(μ)=log(μ)
应用：泊松回归（计数数据）、伽马回归（正偏连续数据）。
特点：确保 μ>0，避免负数预测。
3. Logit 连接（Logit Link）
公式：g(μ)=log(μ/(1−μ))
应用：逻辑回归（二分类问题）。
特点：将概率 μ∈(0,1) 映射到实数域，便于线性建模
