# Isotonic Regression（保序回归 / 等渗回归）：
> 非参数、单调约束回归，只要求拟合函数非递减（或非递增），不强行要求线性
- 输入：一维有序 x（已排序）+ 对应 y
- 输出：一条分段常数、单调不减的阶梯曲线，尽量贴近 y
- 线性回归 = 强行画直线；保序回归 = 只要求不下降，形状自由。
- 给定已排序：
x_1<x_2<x_3<x_4... 
目标：min(Σw_1(y_i-y(预测)_i)^2)  
预测约束：
y_1<y_2<y_3<y_4...  
可用 PAVA 算法（Pool Adjacent Violators Algorithm） 快速求解O(n)
- AVA 算法原理
遍历数据，遇到后一个比前一个小（违反单调）就把这两个区间合并成一块，取均值，反复合并直到全程非递减。
