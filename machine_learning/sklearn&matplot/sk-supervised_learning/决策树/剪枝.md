# 剪枝
> 抑制过拟合，去掉冗余分支，提升泛化能力
## 两类剪枝
1. 预剪枝（生成树时剪）
  - 分裂前判断：本次分裂能否提升验证集精度
  - 不提升就停止分裂，直接设为叶节点
  - 速度快、简单，容易欠拟合
2. 后剪枝（树建好再剪）
  - 先生成完整整棵树，自底向上回溯
  - 把内部节点换成叶节点，对比误差
  - 误差变小 / 不变，就剪掉该分支
  - 效果更好，泛化强，计算慢
3. 四大树剪枝特点
  - ID3：无剪枝，极易过拟合
  - C4.5：自带后剪枝
  - C5.0：优化后剪枝，剪枝力度更大
  - CART：成本复杂度剪枝（CCP 剪枝）
5. 文本公式：
Cost_complexity = Gini_loss + α * leaf_num
α 越大，剪枝越狠
