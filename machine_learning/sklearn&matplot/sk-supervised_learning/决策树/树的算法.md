# ID3 / C4.5 / C5.0 / CART
## ID3-信息增益
> 信息熵公式: Entropy(D) = -sum( p_k * log2(p_k) ) 
p_k = 类别 k 样本数 / 总样本数 
> 条件熵：Entropy(D|A) = sum( |D_i|/|D| * Entropy(D_i))
已知特征 A 的取值后，数据集 D 剩余的不确定性
|D|：总样本数量
|D_i|：特征 A 取第 i 个值对应的样本数
Entropy(D_i)：该子集的信息熵
求和遍历特征 A 所有划分出的子集
> 信息增益：Gain(D,A) = Entropy(D) - Entropy(D|A)
- 特点
  - 优先选信息增益最大特征分裂
  - 只支持离散特征
  - 偏向取值多的特征（缺陷）
  - 不能处理缺失值、连续值
  - 易过拟合

## C4.5-信息增益比
> 公式：Gain_ratio(D,A) = Gain(D,A) / SplitInfo(D,A)  
  SplitInfo(D,A) = -sum( |D_i|/|D| * log2(|D_i|/|D|))
- 用增益比修正 ID3 偏向多取值特征问题
- 支持连续值离散化
- 支持缺失值处理
- 加入后剪枝防过拟合
- 分类树，只能做分类
## CART决策树-基尼系数 Gini
> 公式：Gini(D) = 1 - sum( p_k^2 )，越小越纯净，优先选基尼下降最大特征
- 两大形态
  - CART 分类树：基尼系数，输出类别
  - CART 回归树：均方误差 MSE，预测连续值
- 永远二叉分裂（二分法）
- 不管特征多少取值，全都强行二分
- 可离散、可连续、可分类、可回归
- 常用预剪枝 + 后剪枝
- sklearn 默认决策树就是 CART
## 最简选型
- 只做分类小数据 → C4.5
- 工程上线分类 → C5.0
- 要回归 / 通用建模 → CART
- 老教材考题 → ID3
