# 打分函数（给特征打分）
## 分类任务
- f_classif(方差分析 F 检验，分类)
  - 核心：组间方差 / 组内方差 
  - 特征与标签的 ANOVA F 值，连续特征用，看是否能区分类别。
- mutual_info_classif(互信息)
  > p(x,y)=Σp(x,y)*log(p(x,y)/(p(x)*p(y)))
  - 衡量两个变量信息重叠量 
  - 互信息，捕捉非线性关联，最强最稳。
  - 数值越大，知道特征就能大幅降低类别不确定性，适配线性 + 非线性关系
- chi2
  > ρ^2=Σ(观测频数 - 期望频数)^2/期望频数
  - 衡量特征与类别独立性 
  - 卡方统计量，非负离散特征专用（文本、计数）。
  - 卡方值越大，二者关联越强，特征越有效
##  回归任务
- f_regression
  - F=R^2/(1) / (1-R^2)*(n-2)
  - R 为皮尔逊相关系数，F 越大，特征与连续目标线性相关性越高 
  - 特征与目标的 线性相关 F 值。
- mutual_info_regression
  - 连续变量互信息，积分形式
  - 回归任务的 互信息，非线性也能抓。
二、筛选策略（按分数删特征）
- SelectKBest：特征得分降序排序，截取前 K 个
- SelectPercentile：按得分百分比阈值截取顶部特征
- SelectFpr：依据假设检验 p 值，保留 p<alpha 特征，控制单次假阳性
- SelectFdr：修正多检验偏差，控制整体错误检出比例
- SelectFwe：严控全局犯错概率，筛选标准最严苛
- GenericUnivariateSelect：封装上述所有规则，参数切换筛选模式
# 递归特征消除
> 从所有特征开始，一轮一轮删掉最没用的特征，直到剩下你想要的 K 个。
- RFE = 递归 + 特征消除
- 步骤：
  - 用全部特征训练一个模型
  - 模型给每个特征打分（重要性 / 系数）
  - 删掉分数最低的 1 个 / 几个特征
  - 用剩下的特征重新训练模型
  - 重复 2–4，直到剩下你指定的数量
