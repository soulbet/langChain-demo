# 半监督学习 Semi-supervised Learning
> 核心定义:
少量带标签数据 + 大量无标签数据一起训练，不用全额标注也能建模。
- 适用场景
  - 标注成本高、人工标记少，原始样本极易获取
  - 例：文本分类、图像识别、用户行为分类
- 核心思路
  - 少量标注样本先学到基础规律
  - 利用无标注样本的数据分布、聚类、距离关系
  - 给无标签数据伪标签，扩充训练集迭代优化
- 常见经典算法
1. 自训练 Self-Training
  - 先用标注数据训基础模型，给无标签样本预测标签，置信度高的样本纳入训练集反复迭代。 
2. 协同训练
  - Co-Training拆分两组独立特征，分别训练两个模型，互相筛选高可信无标样本补充对方数据集。
3. 标签传播 
  - Label Propagation基于样本相似度构建图结构，标签顺着邻近相似样本自动扩散传递。
4. 生成式模型
  - 假设数据服从某分布，最大化包含无标数据的联合概率估计标签。
- 优缺点
  - 优点：大幅降低标注成本，海量无标数据提升泛化能力
  - 缺点：伪标签出错易累积偏差，数据分布异常时效果下滑
