# 核函数	代码	适用场景	何时使用
## RBF（径向基）	
- RBF(length_scale=1.0)	  平滑、无限可导的函数	  默认首选，不确定时用它
# Matérn	
- Matern(length_scale=1.0, nu=1.5)	物理过程，有限次可导	数据不光滑（如湍流、粗糙表面）
# 周期性	
- ExpSineSquared(periodicity=24.0)	周期性数据	时间序列有明显周期（如24小时、7天）
# 线性	
- DotProduct(sigma_0=1.0)	线性函数	数据呈线性趋势
# 有理二次	
- RationalQuadratic(alpha=1.0)	多尺度变化	函数在不同尺度都有变化
# 白噪声	
- WhiteKernel(noise_level=1e-5)	观测噪声	通常与其他核组合使用
