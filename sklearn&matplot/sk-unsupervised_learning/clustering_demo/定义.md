# 聚类（Clustering）
> 每个聚类算法都有两个变体:一个是类，它实现了 fit 方法来学习训练数据上的簇，另一个是函数，给定训练数据，返回对应于不同簇的整数标签数组。对于类，可以在 labels_ 属性中找到训练数据上的标签。

## K-means
> K-Means 是一种基于原型的划分式聚类算法，通过迭代优化将数据划分为 K 个簇，使得每个样本到其所属簇中心的距离平方和最小。
- 核心思想
  > K-Means 的目标是将n个样本划分到K个簇中，使得簇内误差平方和（Inertia）最小化：min(Σ||X-μ_k||^2),X∈C_k,K=1  
  > 其中，C_k是样本集合，μ_k=1/|C_k|ΣX，第k个簇的中心，直观理解：找到 K 个中心点，让每个数据点都归属于离它最近的中心，同时让所有点到其中心的总距离最小。
- 算法步骤
  - 样本集 X (n × d)，簇数 K，最大迭代次数 max_iter
  - 输出：簇划分 C = {C₁, C₂, ..., C_K}
  1. 初始化：随机选择 K 个样本作为初始质心 μ₁, μ₂, ..., μ_K
  2. 重复直到收敛或达到最大迭代次数：
   a) 分配步骤：对每个样本 x_i，计算到各质心的距离，分配到最近的簇
        c_i = argmin_k ||x_i - μ_k||²
   b) 更新步骤：对每个簇，重新计算质心（簇内样本的均值）
        μ_k = (1/|C_k|) Σ_{x∈C_k} x
  3. 返回最终簇划分
### 小批量K-means
>小批量 K-Means 是经典 K-Means 的变体，每次迭代只使用一个随机的小批量样本（而不是全部数据）来更新簇中心，从而大幅提升在大数据集上的计算效率。
- 算法步骤
  - 输入：样本集 X，簇数 K，批量大小 batch_size，迭代次数 max_iter
  - 输出：簇中心 μ₁, μ₂, ..., μ_K
  1. 初始化：随机选择 K 个样本作为初始质心
  2. 重复 max_iter 次：
     a) 随机从 X 中抽取 batch_size 个样本，构成小批量 B
     b) 对小批量中每个样本，分配到最近的簇中心
     c) 对于每个簇 k：
        - 计算小批量中属于该簇的样本均值 μ_k^{batch}
        - 更新质心：
            μ_k = μ_k + η * (μ_k^{batch} - μ_k)
          其中 η = 1 / (count_total 或 固定学习率)
     d) 可选：降低学习率
  3. 返回最终簇中心

## Affinity Propagation（亲和传播聚类）
> 亲和传播是一种基于消息传递的聚类算法，它不需要预先指定簇的数量，而是通过在数据点之间传递"责任"和"可用性"两种消息，自动发现簇中心和簇划分。
- 核心思想
  - 想象一场选举：每个数据点都是选民，同时也是潜在的候选人（簇中心）。选民们相互投票，最终选出若干个代表（聚类中心），其他选民则归附到离自己最近的代表。
  - 两种关键消息：
    1. 责任 (Responsibility) r(i,k) 点i认为点 k 适合作为自己代表的证据
    2. 可用性 (Availability)	a(i,k) 点k 认为自己适合作为点i 代表的证据
- 数学原理
1. 定义点i和点j 之间的相似度s(i,j)，通常使用负的欧氏距离：s(i,j)=-||x_i-x_j||^2  
   偏好值 p(i)=s(i,i) 是自相似度，它影响点i 成为簇中心的倾向。通常：
   - p(i) 取相似度的中位数 → 产生中等数量的簇
   - p(i) 取相似度的最小值 → 倾向于更少的簇 
   - p(i) 取相似度的最大值 → 倾向于更多的簇
2. 责任更新
  - 责任更新（从i 到k）：r(i,k)=s(i,k) - max(a(i,k')+s(i,k'))
    - r(i,k) 越大 → 点k 相比其他候选点，越适合做i 的代表当r(i,k)>0 时，表示k 比其它点更适合\
    - a(i,k')+s(i,k') 候选中心k′对i 的综合吸引力
    - 取最大值：找出对i 最具吸引力的其他中心（即最强竞争者） 
    - 相减：衡量k 相比最强竞争者是否有优势
  - 可用性更新，a(i,k)=min(0,r(k,k')+Σmax(o,(i',k)))
    - 对于i=k,a(k,k)=Σmax(0,r(i',k))
    - a(i,k) 是k 收集到的"投给它的票数"的累加a(i,k) 越大 → 点k 作为代表的可信度越高
    - r(k,k') 点k 对自己的“自责任”（想当中心的意愿）
    - Σmax(0,r(i',k)) 其他点对k 的正向支持汇总
  - 当更新后消息的变化小于收敛阈值（默认10^−6）时，算法停止。
    确定簇中心：点k 成为簇中心的条件是：r(k,k)+a(k,k)>0
### 算法流程：
- 输入：样本集 X，偏好值 preferences，最大迭代次数 max_iter，收敛阈值 tol
- 输出：簇中心集合 exemplars，簇分配 labels
1. 计算相似度矩阵 S[i][j] = -||x_i - x_j||²
2. 初始化：R[i][j] = 0, A[i][j] = 0
3. 重复直到收敛或达到 max_iter：
   a) 更新责任矩阵 R
        r[i][j] = s[i][j] - max_{j'≠j}(a[i][j'] + s[i][j'])
   b) 更新可用性矩阵 A
        a[i][j] = min(0, r[j][j] + Σ_{i'≠i,j} max(0, r[i'][j]))
        a[j][j] = Σ_{i'≠j} max(0, r[i'][j])
   c) 阻尼更新（可选）：
        R_new = (1 - λ) * R_new + λ * R_old
        A_new = (1 - λ) * A_new + λ * A_old
4. 选择簇中心：r[i][i] + a[i][i] > 0 的点
5. 分配簇：每个非中心点分配到最近的簇中心
## 谱聚类概念
> 与传统的K-Means算法依赖数据在欧式空间中的距离不同，谱聚类将数据看作图中的顶点，根据数据点之间的相似度构建边，进而将聚类问题转化为图的划分问题。
> 它通过计算图拉普拉斯矩阵的特征值和特征向量（即“谱”），在高维空间中找不到聚类边界的数据，投影到低维空间后往往变得线性可分。
### 谱聚类的做法：
- 把相近的点用线连起来，形成一个图。
- 试图用“剪刀”把这个图剪成几块（比如切掉最少的边，即图切分中的规范切）。
- 数学上，“怎么剪”这个问题等价于求解拉普拉斯矩阵的特征向量。
- 把求出的特征向量组成新的坐标系，在这个新坐标系下，原本纠缠在一起的数据（如同心圆）就被拉直了，然后再用简单的K-Means就能完美聚类。

### 优缺点：
#### 优点：
- 擅长处理非凸数据：对任意形状的聚类簇（如同心圆、半月形、流形结构）都能表现极好，彻底克服了K-Means的局限性。
- 基于全局信息：K-Means基于局部欧式距离，而谱聚类通过图传递，考虑了点与点之间的全局连通路径。
- 数学基础扎实：有严格的图论和线性代数理论支撑，可以推导出与图切分准则（如Min-cut, Ratio-cut, Normalized-cut）的等价关系。

####  缺点：
- 计算复杂度高：构建和存储 N x N的相似度矩阵需要O(N^2),对稠密矩阵进行特征值分解需要需要O(N^3),不适合大规模数据集
- 参数敏感：
 -- 需要预先指定聚类数K.
 -- 高斯核的带宽参数 σ 对结果影响巨大： σ 太小，图会断裂成很多孤立的点； σ 太大，图会变成全连接，失去局部结构。
### 应用场景
- 图像分割：这是谱聚类最经典的落地场景。将图像的每个像素视为图节点，像素间的颜色、纹理相似度视为边的权重，利用Normalized Cut进行分割。
- 社交网络社区发现：将用户作为节点，互动频率或关注关系作为边权重，找出关系紧密的圈子。
- 降维与流形学习：谱聚类的特征向量提取过程本身也是一种非线性降维方法（与LLE、Isomap思想有共通之处）
- 推荐系统与生物信息学：处理复杂的实体关系网络。

## Mean Shift
> Mean Shift 是一种基于密度梯度上升的聚类算法，通过反复将数据点向密度最大的方向移动，最终所有点都会"漂移"到附近的密度峰值（模式），同一个峰值附近的点构成一个簇。
-  核心思想：寻找密度最高点
  > 想象在一片山区中，每个数据点都是一团雾气。Mean Shift 让每团雾气沿着坡度最陡的方向向上爬，直到到达山顶（密度最大点）。最终，爬到同一座山顶的雾气属于同一个簇。
- 算法原理
  - 核密度估计（Kernel Density Estimation, KDE）  
    首先，Mean Shift 假设数据空间中的密度可以用核密度估计来近似：
   > f(x)=1/nhΣk((x-x_i)/h),k:是核函数 h:带宽，控制核半径，d:数据维度
  - 密度梯度  
    对密度函数求梯度，可以得到密度上升最快的方向：
  - Mean Shift 向量
    经过推导，梯度方向可以简化为 Mean Shift 向量：m(x)
  - 更新规则：x=x+m(x)
算法步骤：
- 输入：样本集 X，带宽 h，收敛阈值 ε
- 输出：簇标签 labels
1. 初始化：将每个点标记为未访问
2. 对于每个未访问的点 x：
   a) 将 x 作为起始点
   b) 重复直到收敛：
        - 在带宽 h 内找到所有邻居
        - 计算加权平均位置（Mean Shift 向量）
        - 移动 x 到这个位置
   c) 记录收敛点（密度峰值）
3. 合并距离小于 h/2 的峰值点
4. 将每个原始点分配到最近的峰值点所属的簇
> 带宽的选择：h=(4/d+2)^(d+4)*σ*n^(-1/d+4),其中 σ 是各维度标准差的均值， d 是维度，n 是样本数。
- 优点：
  1. 收敛到密度峰值	     
  2. 只有一个参数（带宽）
  3. 对异常值鲁棒
  4. 能处理非球形簇
  5. 自动发现簇数量
  6. 不需要指定 K	
- 缺点：
  1. 计算复杂 O(n²·T)
  2. 带宽敏感（需调参） 
  3. 高维数据表现差（密度稀疏） 
  4. 大样本（>10000）很慢 
  5. 带宽选择困难  
  6. 可能产生过多或过少簇
- 场景：
不知道 K	✅ 非常好	自动发现
非球形簇	✅ 好	基于密度
图像分割	✅ 经典应用	在像素空间找模式
目标跟踪	✅ 经典应用	迭代漂移定位
小到中样本（<5000）	✅ 好	计算可接受
大样本（>10000）	❌ 太慢	改用 DBSCAN 或 K-Means
高维数据（>20维）	⚠️ 谨慎	密度稀疏，效果差
