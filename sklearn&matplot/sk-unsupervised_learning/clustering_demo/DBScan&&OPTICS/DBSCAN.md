# DBSCAN 
> DBSCAN 是一种基于密度的聚类算法，它将高密度区域中的点归类为簇，同时将低密度区域中的点标记为噪声（异常点）  
> 与 K-Means 不同，你不需要指定簇的数量，而且它可以发现任意形状的簇。
## 核心思想
- 簇 = 被低密度区域分隔开的高密度区域 
- 噪声 = 不在任何高密度区域中的孤立点
- 关键参数
  - Epsilon (ε)	eps	邻域的半径	决定了什么是"附近"
  - MinPts	min_samples	邻域内成为核心点所需的最少点数（包含自身）	决定了什么是"密集"
  > 注意：min_samples 包含自身，所以在代码中通常 min_samples=4 意味着需要 自己和另外 3 个邻居。
- 点的类型
  - 核心点 (Core)	半径 ε 内至少有 min_samples 个点（包含自身）	|N_ε(p)| ≥ min_samples	⬤ 中心实心点
  - 边界点 (Border)	在某个核心点的 ε 内，但自身不是核心点	|N_ε(p)| < min_samples	◌ 边缘空心点
  - 噪声点 (Noise)	不在任何核心点的 ε 内	孤立且不靠近任何核心点	✕ 异常点
## 步骤
- 输入：样本集 X，半径 eps，邻居阈值 minPts
- 输出：簇标签（噪声点标记为 -1）
1. 初始化：所有点标记为未访问
2. 对每个未访问的点 p：
   a) 标记 p 为已访问  
   b) 找出 p 的 ε 邻域内的所有点 N(p)  
   c) 如果 |N(p)| < minPts：  
        标记 p 为噪声（暂定）  
   d) 否则（p 是核心点）：  
        创建一个新簇 C  
        将 N(p) 中的所有点加入"种子集合"（待扩散）  
        重复：  
            - 从种子集合中取一个点 q  
            - 如果 q 未访问：  
                标记 q 为已访问  
                找出 q 的 ε 邻域 N(q)  
                如果 |N(q)| ≥ minPts（q 也是核心点）：  
                    将 N(q) 中未加入簇的点加入种子集合  
            - 如果 q 还不是任何簇的成员，将 q 加入簇 C  
        直到种子集合为空  
3. 返回所有点的簇标签（噪声点为 -1）
## 核心概念
- 直接密度可达	q 在 p 的 ε 邻域内，且 p 是核心点	一步到达
- 密度可达	存在一条链 p₁→p₂→...→pₙ，相邻点直接密度可达	多步到达
- 密度相连	存在点 o，使得 p 和 q 都从 o 密度可达	属于同一个簇
> 一个簇 = 所有相互密度相连的点的最大集合。
## 参数选择
选择 minPts  
经验法则：  
- minPts ≥ 维度 + 1（通常取 2×维度）
- minPts ≥ 4（数据量不大时）
- 数据量大时可以更大（如 10-50）
- 噪声多时增大 minPts
## 优缺点
✅ 不需要指定簇数 K	❌ 对参数 eps, minPts 敏感
✅ 可以识别任意形状的簇（半月形、S形）	❌ 密度不均匀时效果差
✅ 自动识别噪声/异常点	❌ 高维数据表现差（密度稀疏）
✅ 对数据顺序不敏感	❌ 计算复杂度 O(n²)（优化后 O(n log n)）
✅ 只有一个核心参数（eps）	❌ 簇之间密度差异大时难调参
