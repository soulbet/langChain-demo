# Birch
> BIRCH 是一种专门为超大规模数据集设计的层次聚类算法，它通过构建一个叫 CF（Clustering Feature）树 的数据结构，将数据压缩成一个个 聚类特征（子簇的统计摘要），然后对这些摘要进行聚类，从而在有限内存中处理海量数据。

## 核心思想
- BIRCH 的核心创新是 CF（聚类特征）。
- CF 是一个三元组，它完整地、可加性地概括了一个子簇的所有统计信息：
 > CF=(N,LS.SS)  
 N:子簇中数据点的个数
 LS:各数据点向量和
 SS：各数据点向量平方和
- 两个 CF 可以直接相加，无需接触原始数据： CF1+CF2=(N1+N2+LS1+LS2+SS1+SS2)
  - 这意味着你可以： 
  1. 扫描数据，动态构建 CF 树
  2. 随意合并 CF 节点，而无需回溯原始数据
  3. 在内存中只存储 CF 摘要，而不是全部数据
- CF中可以得到哪些信息：
 - 质心：X0=LS / N   代表簇的中心位置
 - 半径：R=sqrt((SS - ||LS||^2) / N)   簇内点到质心的平均距离
 - 直径：D=sqrt((SS - (||LS||^2/N)) / N)   簇内点之间平均成对距离
  > 半径 和 直径 都用来衡量簇的紧密程度，是 BIRCH 决定何时分裂或合并节点的依据。
### CF树的结构
CF 树是一棵高度平衡树，类似于 B 树：
- 非叶子节点：存储子节点的 CF 摘要
- 叶子节点：存储该叶子内所有 CF 条目（每个 CF 是一个微型子簇）
- 所有叶子节点通过双向链表连接，方便扫描
## 算法流程
- 阶段1：构建 CF 树（扫描数据，动态构建）                           
  - 逐个插入数据点                                      
  - 找到最近的叶子 CF                                   
  - 如果加入后直径 ≤ T，则合并                              
  - 否则新建 CF 条目                                   
  - 如果叶子满了，分裂                                    
  - 如果非叶子满了，向上分裂传播

- 阶段2：全局聚类（可选，对叶子 CF 做聚类）                         
  - 将叶子节点的 CF 视为"微型簇"                                 
  - 用传统聚类算法（如 Agglomerative）对 CF 质心聚类               
  - 输出最终簇标签
- 阶段3：簇细化（可选，扫描原始数据重新分配）                      
   - 用阶段2的簇中心，重新扫描原始数据                       
   - 将每个点分配到最近的中心                            
   - 可进一步合并或分裂
