## 1. 核心定义
分位数变换（Quantile Transformation）是一种数据预处理技术，它通过将数据映射到特定分布（通常是正态分布）来实现数据的标准化。这种方法不改变数据的分布形状，但可以改变数据的分布中心和尺度。

## 2. 数学原理/公式
分位数变换的基本原理是将数据的每个值替换为其在目标分布中的分位数。假设原始数据为 \( X \)，目标分布为 \( F \)，则变换后的数据 \( X' \) 可表示为：
$$ X' = F^{-1}(F(X)) $$
其中$$ F^{-1} $$是目标分布的逆累积分布函数（CDF）。

## 3. 关键要点
- 分位数变换可以将数据映射到目标分布（如正态分布）。
- 它不会改变数据的分布形状，但可以改变数据的分布中心和尺度。
- 它可以将数据压缩到 0~1 之间，类似于 MinMaxScaler。
- 它破坏了特征之间的线性关系。
- 它的可解释性变差，因为变成了一种基于排名的映射。

## 4. 代码示例 (Python)
```python
import numpy as np
from sklearn.preprocessing import QuantileTransformer

X = np.array([[1, 2],])
qt = QuantileTransformer(output_distribution='normal', random_state=42)
X_transformed = qt.fit_transform(X)
print(X_transformed)
```

## 6. 优缺点
- 优点: 可以将数据映射到目标分布，适用于需要正态分布的数据；可以将数据压缩到 0~1 之间。
- 缺点: 破坏了特征之间的线性关系；可解释性变差。

## 7. 常用的使用场景
- 数据预处理，特别是需要正态分布的数据。
- 数据压缩，将数据映射到 0~1 之间。
- 处理异常值，分位数变换对异常值具有较好的抗性。
