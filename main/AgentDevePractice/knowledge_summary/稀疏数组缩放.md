## 1. 核心定义
特征缩放（Feature Scaling）是将不同特征的数据缩放到一个统一的范围，通常是[0, 1]或[-1, 1]，以避免某些特征对模型的影响过大。

## 2. 数学原理/公式
- **Min-Max Scaling**: 将数据缩放到[0, 1]范围：$$X' = \frac{X - \min(X)}{\max(X) - \min(X)}$$
- **Standardization**: 将数据缩放到均值为0，标准差为1的分布：$$X' = \frac{X - \mu}{\sigma}$$

## 3. 关键要点
- **Min-Max Scaling** 适用于数据分布已知且范围不大的情况。
- **Standardization** 适用于数据分布未知或需要消除量纲的情况。
- **稀疏矩阵** 使用 `MaxAbsScaler` 可以避免转换为密集矩阵。
- **文本数据** 使用 `TfidfVectorizer` 进行特征缩放。

## 4. 代码示例 (Python)
```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.preprocessing import MinMaxScaler, StandardScaler
from scipy import sparse

# Min-Max Scaling
X_train = np.array([[1, 2], [3, 4], [5, 6]])
scaler = MinMaxScaler()
X_train_scaled = scaler.fit_transform(X_train)

# Standardization
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)

# 处理稀疏矩阵
X_train_sparse = sparse.csr_matrix(np.array([[1, 0, 0], [0, 2, 0], [0, 0, 3]]))
scaler = MaxAbsScaler()
X_train_scaled = scaler.fit_transform(X_train_sparse)

# 处理文本数据
text_data = ["hello world", "hello python"]
vec = TfidfVectorizer()
X_scaled = vec.fit_transform(text_data)
```

## 6. 优缺点
- **优点**:
  - 提高模型训练的效率和收敛速度。
  - 使得某些距离度量（如欧氏距离）更加合理。
- **缺点**:
  - 会丢失数据的原始分布信息。
  - 对异常值敏感。

## 7. 常用的使用场景
- 数据预处理阶段，特别是在使用距离度量或梯度下降算法时。
- 处理稀疏矩阵和文本数据时。
