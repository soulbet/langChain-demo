## 1. 核心定义
特征缩放（Feature Scaling）是指将不同特征的数据缩放到一个统一的范围，通常是[0, 1]或[-1, 1]，以确保每个特征对模型的影响相同。

## 2. 数学原理/公式
特征缩放的公式通常有三种：
1. **最小-最大缩放（Min-Max Scaling）**：$$ x' = \dfrac{x - \min(x)}{\max(x) - \min(x)} $$
2. **标准缩放（Standardization）**：$$ x' = \dfrac{x - \mu}{\sigma} $$
3. **Robust Scaling**：$$ x' = \dfrac{x - \text{median}(x)}{\text{IQR}(x)} $$，其中 IQR 是四分位距，即第75百分位数（Q3）与第25百分位数（Q1）的差值。

## 3. 关键要点
- **最小-最大缩放**：适用于数据分布接近正态分布的情况，但对离群值敏感。
- **标准缩放**：适用于数据分布接近正态分布的情况，对离群值不敏感。
- **Robust Scaling**：适用于数据分布不明确或存在离群值的情况，对离群值不敏感。

## 4. 代码示例 (Python)
```python
import numpy as np
from sklearn.preprocessing import RobustScaler

data = np.array([20, 22, 25, 24, 23, 1000]).reshape(2, 3)
scaler = RobustScaler()
X_scaled = scaler.fit_transform(data)
print(X_scaled)

# 处理离群值
q01 = np.quantile(data, 0.01)
q99 = np.quantile(data, 0.99)
X_capped = np.clip(data, q01, q99)

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_capped)
```

## 6. 优缺点
- **优点**：确保每个特征对模型的影响相同，提高模型的训练效率。
- **缺点**：对离群值敏感，可能需要额外的处理步骤。

## 7. 常用的使用场景
- 数据预处理，确保模型训练的稳定性。
- 支持向量机（SVM）、K近邻（KNN）等对特征尺度敏感的算法。
- 数据可视化，使不同特征的数据在同一尺度上进行比较。
