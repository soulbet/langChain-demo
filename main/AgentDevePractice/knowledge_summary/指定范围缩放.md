## 1. 核心定义
特征缩放（Feature Scaling）是将特征值缩放到一个特定的范围，通常是[0, 1]或[-1, 1]，以避免某些特征的值对模型训练产生过大的影响。

## 2. 数学原理/公式
特征缩放的数学公式如下：
$$X_{\text{scaled}} = \dfrac{X - X_{\text{min}}}{X_{\text{max}} - X_{\text{min}}} \times (X_{\text{new\_max}} - X_{\text{new\_min}}) + X_{\text{new\_min}}$$
其中，$X$ 是原始数据，$X_{\text{min}}$ 和 $X_{\text{max}}$ 分别是数据的最小值和最大值，$X_{\text{new\_min}}$ 和 $X_{\text{new\_max}}$ 是缩放后的最小值和最大值。

## 3. 关键要点
- 特征缩放可以提高模型的训练效率和收敛速度。
- 常用的缩放方法包括 Min-Max 缩放和标准化。
- Min-Max 缩放将数据缩放到指定的范围，对异常值敏感。
- 标准化将数据缩放到均值为0，方差为1的分布。

## 4. 代码示例 (Python)
```python
import numpy as np
from sklearn import preprocessing

X_train = np.array([[ 1., -1.,  2.],
                    [ 2.,  0.,  0.],
                    [ 0.,  1., -1.]])

min_max_scaler = preprocessing.MinMaxScaler(feature_range=(0,1))
X_train_minmax = min_max_scaler.fit_transform(X_train)
print(X_train_minmax)

X_test = np.array([[-3., -1.,  4.]])
X_test_minmax = min_max_scaler.transform(X_test)
print(X_test_minmax)
```

## 6. 优缺点
- 优点: 提高模型训练效率，减少过拟合，对异常值敏感。
- 缺点: 对异常值敏感，可能需要对数据进行预处理。
