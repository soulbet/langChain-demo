## 1. 核心定义
二元化（Binarization）是指将连续或离散的数值数据转换为二进制形式，通常用于特征预处理，将数据转换为 0 和 1 的形式。

## 2. 数学原理/公式
给定一个数值 \( x \) 和一个阈值 \( \theta \)，二元化操作可以表示为：
$$ \text{binarize}(x, \theta) = \begin{cases} 1 & x \geq \theta \\ 0 & x < \theta \end{cases} $$

## 3. 关键要点
- **阈值（Threshold）**：用于判断数据是否被二元化为 1。
- **输入数据**：可以是连续或离散的数值数据。
- **输出数据**：二进制形式的 0 和 1。

## 4. 代码示例 (Python)
```python
from sklearn import preprocessing

X = [[ 1., -1.,  2.],
     [ 2.,  0.,  0.],
     [ 0.,  1., -1.]]

# 默认 threshold=0.0
binarizer = preprocessing.Binarizer().fit(X)  # fit does nothing

print(binarizer.transform(X))
```

## 6. 优缺点
- **优点**：简化数据，便于后续的机器学习模型处理；可以突出数据中的重要特征。
- **缺点**：可能会丢失数据中的信息，特别是当阈值选择不当时；对于某些模型可能不是最佳选择。

## 7. 常用的使用场景
- 特征预处理：在机器学习模型之前对数据进行二元化处理。
- 图像处理：将图像的像素值二元化，用于图像分割等任务。
- 数据压缩：通过二元化减少数据的存储空间。
