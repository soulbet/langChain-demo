## 1. 核心定义
Z-Score 标准化是一种特征缩放技术，将数据转换为均值为 0，标准差为 1 的分布。

## 2. 数学原理/公式
$$ X_{ij} = \frac{X_{ij} - \mu_i}{\sigma_i} $$
其中 \( X_{ij} \) 是原始数据，\( \mu_i \) 是特征 \( i \) 的均值，\( \sigma_i \) 是特征 \( i \) 的标准差。

## 3. 关键要点
- 将数据缩放到均值为 0，标准差为 1。
- 适用于基于距离或梯度的模型，如逻辑回归、SVM、KNN。
- 不改变数据的分布形状。

## 4. 代码示例 (Python)
```python
from sklearn import preprocessing
import numpy as np

X_train = np.array([[ 1., -1.,  2.],
                    [ 2.,  0.,  0.],
                    [ 0.,  1., -1.]])

scaler = preprocessing.StandardScaler().fit(X_train)
print(f"平均数：{scaler.mean_}")
print(f"标准差：{scaler.scale_}")
print(f"标准化后的数据：{scaler.transform(X_train)}")
```

## 6. 优缺点
- 优点: 标准化后的数据具有可比性，便于模型训练。
- 缺点: 对异常值敏感，异常值会显著影响均值和标准差的计算。

## 7. 常用的使用场景
- 逻辑回归
- 支持向量机 (SVM)
- K-近邻 (KNN)
- 任何基于距离或梯度的机器学习模型
