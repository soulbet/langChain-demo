## 1. 核心定义
Min-Max 归一化是一种特征缩放方法，将特征缩放到一个固定的范围，通常是 [0, 1]。

## 2. 数学原理/公式
$$ X' = \frac{X - X_{min}}{X_{max} - X_{min}} $$

## 3. 关键要点
- 将特征缩放到 [0, 1] 范围内。
- 对于每个特征，计算其最小值 \( X_{min} \) 和最大值 \( X_{max} \)。
- 每个特征的值减去最小值，然后除以最大值与最小值的差。

## 4. 代码示例 (Python)
```python
import numpy as np
from sklearn.preprocessing import MinMaxScaler

X = np.array([[0., -3., 1.],
              [3., 1., 2.],
              [0., 1., -1.]])

scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)
```

## 6. 优缺点
- 优点: 简单易用，计算速度快。
- 缺点: 对异常值敏感，如果存在异常值，可能会导致归一化结果不准确。

## 7. 常用的使用场景
- 数据预处理，确保特征在同一量纲下。
- 训练机器学习模型，如支持向量机、神经网络等。
