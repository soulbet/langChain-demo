## 1. 核心定义
整数编码（Integer Encoding）是将分类数据转换为整数形式的一种方法，用于机器学习模型中处理分类特征。

## 2. 数学原理/公式
- **OrdinalEncoder**：将类别转换为整数，并且强行规定它们之间有大小/顺序关系。
- **OneHotEncoder**：为每一个类别创建一个全新的“是/否（0或1）”列，承认类别之间毫无大小关系。

## 3. 关键要点
- **OrdinalEncoder**：适用于有内在顺序关系的类别。
- **OneHotEncoder**：适用于无内在顺序关系的类别。
- **LabelEncoder**：专门用于处理“标签（目标变量 Y）”，不应用于处理“特征（X）”。

## 4. 代码示例 (Python)
```python
from sklearn import preprocessing

# OrdinalEncoder 示例
enc = preprocessing.OrdinalEncoder()
X = [['male', 'from US', 'uses Safari'], ['female', 'from Europe', 'uses Firefox']]
enc.fit(X)
print(enc.transform([['female', 'from US', 'uses Safari']]))

# OneHotEncoder 示例
from sklearn.preprocessing import OneHotEncoder
X = [["红"], ["绿"], ["蓝"]]
enc = OneHotEncoder(sparse_output=False)
print(enc.fit_transform(X))

# LabelEncoder 示例
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
y = ["猫", "狗", "狗", "猫", "鸟"]
y_transformed = le.fit_transform(y)
print(y_transformed)
y_original = le.inverse_transform(y_transformed)
print(y_original)
```

## 6. 优缺点
- **OrdinalEncoder**：
  - 优点：简单易用，适用于有内在顺序关系的类别。
  - 缺点：可能会引入不准确的顺序关系，影响模型性能。
- **OneHotEncoder**：
  - 优点：不会引入不准确的顺序关系，适用于无内在顺序关系的类别。
  - 缺点：可能会增加特征维度，导致计算复杂度增加。
- **LabelEncoder**：
  - 优点：简单易用，适用于处理标签。
  - 缺点：不适用于处理特征，可能会引入不准确的顺序关系。

## 7. 常用的使用场景
- **OrdinalEncoder**：适用于有内在顺序关系的类别，如性别、教育水平等。
- **OneHotEncoder**：适用于无内在顺序关系的类别，如颜色、品牌等。
- **LabelEncoder**：适用于处理标签，如分类任务中的目标变量。
